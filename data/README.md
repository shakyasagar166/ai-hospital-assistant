# Hospital Healthcare Data Catalog

This directory contains database schemas and realistic clinical seed data for the AI Hospital Assistant.

## Files:
* `schema.sql`: Full MySQL 8.0 DDL definitions for users, departments, doctors, appointments, lab tests, conversations, and messages.
* `hospital_data.json`: Structured seed dataset featuring 8 medical departments, 16 specialist doctors, 12 diagnostic lab tests, and hospital clinical protocols.
