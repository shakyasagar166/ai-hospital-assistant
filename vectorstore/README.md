# Hospital Vector Store

This directory contains persistent ChromaDB vector collections for the AI Hospital Assistant.

Embeddings are generated with `sentence-transformers/all-MiniLM-L6-v2` and contain:
* Clinical triage guidelines & emergency symptom checklists
* Hospital policies, visiting hours, inpatient & outpatient admission guides
* Insurance TPA panel list and cashless claim requirements
* Pre-diagnostic fasting & laboratory test preparation instructions
* Patient rights and medical billing FAQs
